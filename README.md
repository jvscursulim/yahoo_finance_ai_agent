## How to install

* Prerequisites
    * `python==3.11`

1. Clone this repository
```bash
git clone https://github.com/jvscursulim/yahoo_finance_ai_agent.git
```

2. Create an virtual environment
```bash
python -m venv env
```

3. Activate your virtual environemnt

4. Install `pipenv`
```bash
pip install pipenv
```

5. Install dependencies
```bash
pipenv install
```

6. Install `ollama`

7. Download the model `llama3.1:8b`
```bash
ollama pull llama3.1:8b
```

## How to use

1. Start streamlit
```bash
streamlit run src/home.py
```
